Aide – Gestion des tournois

Guide complet pour organiser, gérer et participer aux tournois sur HubISoccer

1. Créer un tournoi

1

Choisir le type de tournoi

Sur la page d'accueil du module, cliquez sur « Créer un tournoi ». Sélectionnez le type :
— Public Show You : accessible à tous (code d'accès public).
— Public Détection : réservé aux footballeurs ayant validé le premier-pas.
— Privé HubISoccer : pour les membres de l'espace privé.
— Privé Simple : nécessite un paiement forfaitaire (pour les organisateurs externes).

2

Remplir les informations générales

Nom du tournoi, sport, dates, lieu, description, logo et affiche, montant de la participation, code d'accès. Vous pouvez également ajouter un flux vidéo (YouTube, Twitch) pour la retransmission.

3

Définir les récompenses et le règlement

Configurez le podium et les récompenses spéciales (meilleur buteur, meilleur gardien, etc.). Ajoutez un règlement spécifique si besoin — il s'ajoute au règlement général de la plateforme.

4

Valider la création

Le tournoi apparaît alors dans la liste des tournois. Les inscriptions sont ouvertes selon les modalités choisies.

2. Gérer les inscriptions

Depuis votre tableau de bord (« Mes tournois » puis « Gérer »), vous pouvez :

  • Visualiser la liste des demandes d'inscription (en attente).
  • Approuver ou rejeter chaque demande.
  • Inviter directement des équipes ou des footballeurs (page « Inviter des participants »).
  • Exporter la liste des participants (CSV).
Astuce : pour les tournois publics avec code d'accès, assurez-vous de communiquer le code aux personnes concernées. Pour les tournois privés simples, le paiement du forfait est requis avant validation.

3. Organiser les matchs

Une fois les inscriptions validées, vous pouvez créer les rencontres :

  1. Dans la gestion du tournoi, onglet « Matchs » → « Ajouter un match ».
  2. Sélectionnez les deux équipes, la date, le lieu, et éventuellement l'URL du streaming.
  3. Les matchs apparaissent dans le calendrier du tournoi et dans la page détail.
  4. À l'issue du match, saisissez le score et les rapports (arbitre, commissaire, médical) depuis la page « Détails d'un match ».

Les classements se mettent à jour automatiquement à partir des résultats saisis.

4. Saisir les rapports de match

Chaque match peut être accompagné de trois types de rapports :

  • Rapport arbitre : score, cartons, incidents.
  • Rapport commissaire : affluence, organisation, observations.
  • Rapport médical : blessures, interventions.

Pour y accéder, cliquez sur « Rédiger un rapport » dans les détails du match. Les rapports sont ensuite consultables et exportables (PDF, Excel, Word).

5. Suivre les classements et statistiques

Les classements sont calculés automatiquement à partir des résultats et sont visibles dans « Classements ». Vous y trouverez :

  • Classement général des équipes (points, victoires, etc.)
  • Meilleurs buteurs, meilleurs passeurs
  • Statistiques par footballeur (cartons, matchs joués)

Les statistiques individuelles alimentent le profil de chaque footballeur sur la plateforme, consultable depuis « Statistiques footballeur » et comparable via « Comparer les stats ».

6. Gestion des récompenses

Les récompenses configurées à la création (podium et catégories spéciales) sont attribuées à une équipe ou à un footballeur dans l'onglet « Primes » de la gestion du tournoi, une fois les résultats connus.

7. Foire aux questions (FAQ)

Comment modifier les informations d'un tournoi après sa création ?
Rendez-vous dans « Mes tournois », cliquez sur « Gérer » puis sur l'onglet « Informations ». Vous pourrez y modifier le nom, les dates, le lieu, le logo, l'affiche, les récompenses, etc.
Que faire si une équipe se désiste en cours de tournoi ?
Vous pouvez déclarer le forfait dans la gestion des matchs concernés. Le classement sera ajusté automatiquement. Pour les tournois avec récompenses, l'équipe forfaitaire peut perdre ses droits.
Comment transférer un footballeur d'une équipe à une autre ?
Depuis « Demande de transfert », sélectionnez le footballeur et l'équipe de destination. La demande apparaît ensuite dans les demandes en attente, à valider par l'organisation.
Puis-je ajouter un flux vidéo après la création du tournoi ?
Oui, modifiez les informations du tournoi et renseignez l'URL du flux. Celui-ci sera alors visible dans la page du tournoi et dans la page dédiée « Diffusion en direct ».
Comment exporter les résultats du tournoi ?
Dans la page « Export rapport de match », un bouton permet de télécharger les rapports au format PDF, Excel ou Word pour chaque match.

8. Besoin d'aide supplémentaire ?

Si vous rencontrez un problème technique ou une question non traitée ici, vous pouvez :

  • Contacter le support via le formulaire dans « Support » (accessible depuis la navbar).
  • Consulter le Règlement général pour les aspects juridiques.
  • Rejoindre la communauté sur le « Feed » pour échanger avec d'autres organisateurs.
